# Matt Krueger's CS-499 ePortfolio

## About me
I’ve been in the Computer Science program for four years, during which I’ve developed key technical skills in both front-end and back-end development, collaborated using source control tools, and learned software quality control through testing methodologies and development lifecycle studies. As part of my coursework enhancements, I’m focused on demonstrating my abilities. My first enhancement demonstrates my ability to design complex systems tooling such as containerization to standardize development and runtime environments. I did this by containerizing my Rescue Dog Search python project, such that the entire stack can be deployed through a single Docker Compose command. I also enhanced this project to demonstrate my full stack development skills by creating a powerful front end dashboard to read, filter, and add data maintained in a NoSQL database. It also demonstrates my ability to utilize and integrate with third-party APIs and frameworks to provide enormous value to my project. I enhanced a Java contact tracking library to provide efficient fuzzy searching against partial matches. This demonstrates my mastery of data structures and algorithms by using quick sorts and hash tables to prove the best possible performance at any scale. Each codebase is scanned with vulnerability scanners, and employ best practices to ensure secure coding standards. These skills directly align with my career goal of becoming a senior-level solutions architect engineering consultant, as they strengthen my technical expertise and leadership potential. My enhancements also support my targeted specialization by showcasing my ability to solve problems across all layers of a system, automate workflows for efficiency, and improve project utility through thoughtful design. My code review and work with source control demonstrate my collaboration skills.
